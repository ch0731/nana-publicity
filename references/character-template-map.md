# 角色 → 风格族映射表

## 映射规则

1. **角色→风格族匹配**：角色名完全匹配时映射到风格族，族内递减随机选择模板
2. **风格相似匹配**：未精确匹配时，根据角色特征推荐相似风格族
3. **全部20套递减随机兜底**：完全无匹配时，从全部20套模板中递减随机抽取

> 2026-05-11 更新：映射改为角色→风格族架构，族内递减随机，不再绑定单模板。
